# Contributing to ARTIFACT Futures

Thank you for your interest in contributing to **ARTIFACT Futures**!

## Great Places to Contribute

- WebGPU / Three.js shader performance and graceful fallback polish.
- Bilingual typography, responsive layout, and reduced-motion accessibility.
- West Bund exhibition preview playback controls and documentation.

## Workflow

1. Fork the repository and create a branch (`feat/...` or `fix/...`).
2. Run `bun install && bun run check && bun run build` (and verify `exhibitions/westbund/index.html` if touching exhibition assets).
3. Keep changes focused and avoid committing `.DS_Store`, API keys, model weights, or user-specific IDE state (`xcuserdata/`).
4. Open a pull request describing what changed and how you verified it.

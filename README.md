# ARTIFACT Futures

This repository contains the online ARTIFACT website and a separate West Bund exhibition prototype.

## West Bund 2026 — current version

Open [exhibitions/westbund/index.html](exhibitions/westbund/index.html) in a browser after cloning or downloading the repository. No installation is required for the exhibition preview.

The [exhibition README](exhibitions/westbund/README.md) describes playback, visitor simulation, source material, and the editable source. The exhibition is independent of the online Next.js site.

## Online website

```sh
bun install
bun dev
```

Validation: `bun run check` and `bun run build`.

## Archived proposals

[archive/westbund](archive/westbund/README.md) contains the superseded website-based exhibit and twelve earlier design studies. The old `/en/exhibit` route has been retired; use the current standalone preview above.

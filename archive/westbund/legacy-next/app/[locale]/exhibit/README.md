# 展台预演

入口：`/en/exhibit`。仍使用现有 Next.js、Home、GSAP 和原有素材，无新增依赖或服务。

默认展示整段交互动画并循环播放，控制收在左下角“展台”悬浮胶囊中，点击展开。屏幕边界、实体书落点与纯净输出收在“显示设置”中。页面没有视频小窗、媒体上传或摄像头预览。

三块 16:9 横屏沿短边相接，共用一个 2880 × 540 的逻辑画面与一条首页时间线。预览中的分界线仅用于校对。Issue 实体书默认在第一屏偏右、屏幕下方，可拖动到三屏下方任意位置，动画落点同步跟随。进入大屏会隐藏控制区、分界线和模拟实体书。

现场校准：直接拖动书本，或在胶囊 → 显示设置中调整横向位置和距屏幕下沿的距离；书本获得焦点后也可用方向键微调，Shift + 方向键加大步长。位置以相对屏幕的比例保存在当前浏览器，刷新后恢复；“恢复默认位置”回到第一屏偏右。预览会限制书本在屏幕下方的可见区域，避免遮住画面或被窗口边缘裁切；纯净输出使用同一落点。

在现场，把浏览器窗口放到横向扩展的三屏桌面上，再使用浏览器或显卡提供的跨屏输出。此版本是一张全景画布，不包含三台独立电脑之间的网络同步。屏幕分辨率或缩放不一致时，应先在系统显示设置中统一。

## 播放与意图

- 初始交互关闭，首页按原顺序循环，基准周期 120 秒。
- 交互开启后：无人 1.5×，有人 0.55×。公共时间线持续播放。
- 每人一张来自原鼠标封面素材库的封面，按稳定 ID 跟随横向位置。
- 连续面向屏幕、位置保持在全宽的 0.8% 范围内 3 秒后触发。画面中的细线显示驻足进度。
- 封面以条带变形方式弯曲、拉长并收窄，约 1.35 秒内朝当前实体书位置离屏。减少动态效果偏好下改为淡出。
- 一次连续停留只触发一次，离场超过 0.8 秒后可再次触发。短暂缺失或低置信度会清除当前驻足计时，不把丢失时间算作观看时间。
- 暂停同时冻结展示、模拟、驻足计时和飞行动画；拖动展示进度会重置人物状态；重播从头开始。
- 接近的封面会分配不同高度，人物的计时与触发互不覆盖。最多接收 8 人。
- 首页内容、字体和页面均保留；Programme 原本的悬停预览在展台中按可见条目自动展示。普通首页仍保持原鼠标行为。

快捷键：Space 暂停/播放，I 交互开关，R 重播，Esc 退出大屏。

## 人物接口

选择“手动模拟”或“自动演示”可评审交互；现场识别系统通过下列人物接口驱动，不在页面中显示摄像头画面。

在展台窗口派发事件（前端接入），或从同源窗口使用 `postMessage`：

```js
const people = [
  { id: "person-1", x: 0.72, facing: true, confidence: 0.95 },
];
window.dispatchEvent(new CustomEvent("artifact:audience", { detail: { people } }));
// 或 exhibitWindow.postMessage({ type: "artifact:audience", people }, location.origin);
```

选择“外部信号”并开启交互。`x` 为整个三屏墙从左到右的 0–1 坐标；`facing` 表示面向屏幕，不代表眼球注视。保持人物 ID 稳定，建议每秒 10–30 帧，离场发送空数组。超过 0.5 秒未更新即视为信号缺失。低于 0.65 的 confidence 不参与触发；省略 confidence 时为 1。无效或重复 ID 的整帧被忽略，同源限制默认开启。

## 验证

`bun test scripts/exhibit-audience.test.ts` 覆盖驻足、转身、移动、独立身份、丢失/低置信度、重入与输入校验。`npm run check` 和 `npm run build` 检查整个应用。

实际三屏硬件、相机映射、识别准确度和现场停留阈值需在设备上联调。无 WebGPU 时保留原时间线并使用 Canvas 2D 呈现图片及抖色，鼠标布料效果仍由原 WebGPU 实现负责。
